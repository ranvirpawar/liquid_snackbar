## 0.1.0

- Extract the glass notification interaction into a Flutter-only package.
- Add scoped overlay hosts, context calls, and opt-in navigator/overlay controllers.
- Add bounded FIFO queues, replacement, duplicate suppression, lifetime handles,
  dismissAll and clearQueue with explicit completion reasons.
- Add ThemeExtension styling, custom variants, compact pills, actions and progress.
- Add keyboard avoidance, RTL, accessible live regions, 48dp buttons, Escape,
  reduced-motion fades, optional haptics and exception-safe cleanup.
