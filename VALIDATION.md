## Reproduce

```sh
flutter pub get
flutter analyze
dart format --set-exit-if-changed .
flutter test --coverage
dart run tool/check_coverage.dart
cd example
flutter test
flutter build apk --debug
flutter build web
cd ..
flutter test --platform chrome
dart pub publish --dry-run
dart pub global activate pana
dart pub global run pana .
```

When switching SDK versions, run flutter clean before rebuilding; generated
engine-specific shader artifacts cannot be reused reliably between SDKs.
CI uses fresh checkouts. Capture the preview with
flutter test tool/capture_preview.dart.

The old SDK lockfile issue is resolved by running the installed SDK with
filesystem permission to its cache. No OMS SDK was changed.
